# Scan Missing Textures

Scans your texture folders and finds missing files using a large curated list of GTA SA-related keywords (roads, asphalt, dirt, grass, concrete, rock, sand, etc.).

Extremely useful for environment textures where gaps are hard to notice visually.

## How to use

1. Edit the folder paths near the top of `scan_missing.py` if needed.
2. Run:
   ```bash
   python scan_missing.py
   ```

It will generate a report of missing textures based on the keyword system.
