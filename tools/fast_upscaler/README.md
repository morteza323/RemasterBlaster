# Fast Upscaler (without diffusion)

Lightweight batch upscaler that does **not** use diffusion / generative models.

Faster alternative when you only need classic upscaling (Real-ESRGAN style or similar) without AI hallucination.

## How to use

```bash
# Windows
run_upscaler.bat

# or
python gta_batch_upscaler.py
```

Check `upscaler_settings.json` for configuration.
